Easy Notepad: A Free Online Notepad for Writing and Sketching

Easy Notepad is a browser-based notepad for drafting notes, organizing checklists, and sketching ideas. You can start writing without creating an account. Notes are saved in the current browser, and optional sync can make selected notes available on another device.

Open the online notepad

Rich-text note taking

Format notes with headings, quotes, code blocks, lists, links, text colors, and highlights. Search your notes, pin important items, use find and replace, and track word and character counts.

Checklists and focused writing

Create task lists and checklists, use focus mode, and adjust the zoom level to suit your screen.

Freehand drawing and editable shapes

Sketch ideas with a freehand pen and eraser, or add and edit shapes directly on the page.

Import, export, and backups

Import TXT, Markdown, and HTML files. Export notes as TXT or HTML, or create a JSON backup that can later be restored. Browser storage is tied to the browser profile, so keep a backup of important notes.

Page layouts and PDF output

Choose supported page sizes and orientations, then use print or your browser's PDF-saving option to create a document.

Offline access and app installation

The app can cache its shell for offline reopening after it has been loaded. Previously saved notes remain on the device. Offline availability depends on the browser cache and device storage; syncing requires an internet connection. On supported browsers, install it as a progressive web app (PWA).

Optional sync between devices

Cloud sync is optional and uses a shared sync key. It is not end-to-end encrypted: anyone who has the key can read and change notes stored under it. Do not use sync for passwords or sensitive information.

Privacy and storage

By default, notes are stored in browser local storage rather than requiring an account. Browser data can be cleared by browser settings, and local notes do not automatically appear on other devices unless you use sync or transfer a backup.

Who is it for?

Easy Notepad is useful for quick drafts, personal notes, study notes, simple task lists, meeting notes, and rough visual ideas. It is a lightweight tool, not a substitute for a managed document system or encrypted password manager.
