Easy Notepad Frequently Asked Questions

Practical answers about using this online notepad, storing notes, working offline, and moving notes between devices.

Is Easy Notepad free to use?

You can open and use the web app without creating an account. Check the live website for current availability and terms.

Where are my notes saved?

By default, notes are saved in local storage in the current browser profile on your device. Browser data can be cleared, so export a backup of important notes.

Can I use Easy Notepad offline?

After the app shell has been cached, it may reopen offline and use notes already saved on the device. Cloud sync requires an internet connection.

Does Easy Notepad sync notes between devices?

Optional cloud sync is available using the same sync key on each device. Sync requires an internet connection.

Is cloud sync end-to-end encrypted?

No. Cloud sync is not end-to-end encrypted. Anyone with the sync key can read and change notes stored under that key. Do not store passwords or sensitive information.

Can I export or back up my notes?

You can export notes as TXT or HTML and create a JSON backup that can be restored later.

Can I import existing notes?

The app supports importing TXT, Markdown, and HTML files.

Can I install Easy Notepad on my phone or computer?

It is an installable progressive web app on supported browsers. On iOS, use the browser Share menu and Add to Home Screen where available.

Are my local notes automatically backed up to the cloud?

No. Local notes stay in the current browser unless you explicitly configure optional sync or export a backup.

What types of notes can I create?

You can create rich-text notes, lists and checklists, and pages with freehand drawings or editable shapes.

What file formats can I import and export?

Import TXT, Markdown, and HTML. Export notes as TXT or HTML; use the JSON backup and restore feature for a full backup.
